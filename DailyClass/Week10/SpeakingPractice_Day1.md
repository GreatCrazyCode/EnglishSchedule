
# Day 1: Speaking Practice (口语练习)

## Topic (话题)
Having a Performance Appraisal (进行绩效评估)

## Key Vocabulary (核心词汇)
*   **appraisal** (评估)
*   **performance** (表现)
*   **objectives** (目标)
*   **gone well** (做得好)
*   **didn't go so well** (做得不好)

## Practice Questions (练习问题)
1.  **Warm-up:** Have you ever had an "appraisal" at work or school? How did you feel about it?
    (你在工作或学校有过“评估”吗？你感觉如何？)

2.  **Warm-up:** Do you think performance reviews are useful? Why or why not?
    (你认为绩效评估有用吗？为什么？)

3.  **Core:** How can you prepare for an appraisal to make sure it is a positive experience?
    (你如何为评估做准备，以确保它是一次积极的经历？)

4.  **Core:** When discussing things that "didn't go so well," how can you talk about your weaknesses in a positive way?
    (在讨论“做得不太好”的事情时，你如何以积极的方式谈论自己的弱点？)

5.  **Extension:** What kind of "objectives" would you like to set for yourself for the next year?
    (你希望为自己明年的工作设定什么样的“目标”？)

6.  **Extension:** If you were a manager, how would you give feedback to an employee to help them improve?
    (如果你是一名经理，你会如何给员工反馈以帮助他们进步？)
