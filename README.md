## 核心目标
根据 `./EnglishAtWork_Resource` 中的课程内容，为一位 **B1级别** 的学习者，自动生成一个结构化的每周学习计划。

## 生成范围
从./EnglishAtWork_Resource中 序号24开始到序号66结束, 再根据已有的周文件夹 (例如 `Week1`) 中的课程来决定起始编号。

## 生成规则
1.  **学习周期**: 每周学习四天（周一至周四），周五复习，周六、日休息。
2.  **目录结构**: 每周的学习内容将存放在独立的周文件夹中 (例如 `Week1`, `Week2`)。
3.  **每日课程**: 为周一至周四生成每日学习文件，存放在对应的周文件夹下。
    *   **命名格式**: `Day[天数]-[课程编号]_[课程标题].md` (例如: `Day1-01_AN INTRODUCTION.md`)
4.  **口语练习**:
    *   每日根据当天的学习内容生成一份口语练习文件 (`SpeakingPractice_Day[X].md`)。
5.  **每周复习**: 每周五生成一份周度总结，命名为 `WeeklyReview_Day[X]-Day[Y].md`，并存放在对应的周文件夹下。

## 每日课程内容 (B1 Level)
1.  **学习资料 (Link to Material)**
    *   提供指向 `EnglishAtWork_Resource` 中对应课程的url链接。url链接在./EnglishAtWork_Resource/目录.md中
    *   格式: `[01_AN INTRODUCTION](https://www.bbc.co.uk/learningenglish/english/features/english-at-work/english-at-work-intro)`
2.  **Useful Vocabulary (5-8个)**
    *   列出5-8个核心词汇，提供音标和中文解释。
3.  **Key Expressions (3-5个)**
    *   列出3-5个实用表达式，提供中文解释和1-2个替换或应用场景的例句。
4.  **Exercises (2个)**
    *   设计2个不同类型的练习题，以巩固学习内容，题目需中英双语展示。
    *   **题型1**: 填空题 (使用本课的词汇或表达式)。
    *   **题型2**: 句子改写或情景问答 (例如: "如果你遇到...情况，你会用今天学的哪个表达式来回应？")。

## 每周总结内容生成
1.  **引言**: 简要总结本周的学习主题，例如“职场沟通技巧”。
2.  **主题回顾**: 分别列出 Day 1 到 Day 4 的每日学习主题，并用一句话概括核心内容。
3.  **核心词汇和短语**: 整合本周所有学习过的重点词汇和关键表达式，并进行分类（例如：动词/动词短语、名词、按主题分类的关键表达式）。
4.  **综合练习 (1个)**: 设计一个小型情景对话任务，要求学习者运用本周所学的至少 **4个** 核心词汇或表达式。题目需要中英文展示.
5.  **文件存放**: 生成的文件放在对应的周文件夹下, 文件名为`WeeklyReview_Day1-Day4.md`。

## 每日口语练习生成规则
每日将根据当天的课程内容，生成一份口语练习文件。该文件将同时用于**用户学习**和**AI口语陪练**。

### 文件生成细则
1.  **文件名**: `SpeakingPractice_Day[X].md`
2.  **存放位置**: 对应的周文件夹下。
3.  **内容来源**: 基于当天的课程，设计一个相关的对话话题。
4.  **内容格式 (中英双语)**:
    *   **话题 (Topic)**: 简要描述对话主题。
    *   **核心词汇 (Key Vocabulary)**: 列出需要练习的核心词汇和表达式。
    *   **练习问题 (Practice Questions)**: 设计5-6个有层次的练习问题。
        *   **热身问题 (1-2个)**: 简单、开放式的问题。
        *   **核心问题 (2-3个)**: 紧扣主题和核心词汇。
        *   **扩展问题 (1-2个)**: 假设性或开放性问题。
