# Topic 2: Daily Stand-ups & Progress Updates (日常站会与进度更新)

This guide covers key English vocabulary, phrases, and a sample dialogue for daily stand-up meetings (Scrum meetings) in a frontend development context.

---

## 1. Key Vocabulary (核心词汇)

| English | Chinese | Example / Notes |
| :--- | :--- | :--- |
| **Stand-up** | 站会 | Let's start our daily **stand-up**. |
| **Blocker** / **Impediment** | 障碍 / 阻碍 | Do you have any **blockers**? |
| **Progress** | 进度 | What's the **progress** on the login page? |
| **Ticket** / **Task** | 任务单 / 任务 | I'm working on **ticket** #123. |
| **Status** | 状态 | What's the **status** of the API integration? |
| **On track** | 按计划进行 | The project is **on track**. |
| **Behind schedule** | 落后于计划 | We are a bit **behind schedule**. |
| **Ahead of schedule** | 提前于计划 | We are **ahead of schedule**. |
| **Wrap up** | 完成 / 收尾 | I'll **wrap up** the styling today. |
| **Pick up** | 领取 (任务) | I'll **pick up** the next ticket from the backlog. |
| **Code Review** | 代码审查 | My PR is ready for **code review**. |
| **Merge** | 合并 | I'll **merge** the branch after approval. |
| **QA** (Quality Assurance) | 测试 | The feature is ready for **QA**. |

## 2. Common Phrases (常用短语)

**Yesterday (昨天做了什么)**
*   "Yesterday, I worked on the user profile component." (昨天，我开发了用户个人资料组件。)
*   "I fixed the bug related to the navigation bar." (我修复了导航栏相关的 bug。)
*   "I spent most of the day debugging the API issue." (我昨天大部分时间都在调试 API 问题。)
*   "I completed the layout for the dashboard." (我完成了仪表盘的布局。)

**Today (今天计划做什么)**
*   "Today, I plan to finish the unit tests." (今天，我计划完成单元测试。)
*   "I will continue working on the payment integration." (我将继续做支付集成。)
*   "I'm going to pick up the ticket for the search feature." (我准备领取搜索功能的任务单。)
*   "I'll be focusing on refactoring the legacy code." (我将专注于重构遗留代码。)

**Blockers (遇到的障碍)**
*   "I have no blockers." (我没有遇到障碍。)
*   "I'm blocked by the backend API. It's returning a 500 error." (我被后端 API 阻塞了。它返回 500 错误。)
*   "I'm waiting for the design assets from the UX team." (我在等 UX 团队的设计资源。)
*   "I need some clarification on the requirements for this ticket." (我需要澄清一下这个任务单的需求。)

## 3. Sample Dialogue (情景对话)

**Context:** A daily Scrum meeting via Zoom.
**Participants:**
*   **Scrum Master:** Facilitator (敏捷教练/主持人)
*   **You:** Frontend Developer (你)
*   **Backend Dev:** (后端开发)

**Scrum Master:** "Good morning everyone. Let's do a quick round. **You**, do you want to go first?"

**You:** "Sure. **Yesterday**, I finished implementing the responsive layout for the landing page and submitted a PR. **Today**, I plan to address the comments on that PR and then start working on the 'Sign Up' form validation. **I don't have any blockers at the moment**, but I might need some help from the design team later to clarify the error message styles."

**Scrum Master:** "Okay, thanks. If you need design support, just ping them on Slack. Next, Backend Dev?"

**Backend Dev:** "Yesterday I was working on the user authentication API. I ran into some issues with the database migration, so I'm a bit **behind schedule**. **Today**, I'll focus on fixing that. **I am blocked** until the database admin grants me the necessary permissions."

**Scrum Master:** "I see. I'll reach out to the DBA right after this meeting to get that sorted. Let's keep moving..."
